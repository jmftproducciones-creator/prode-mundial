# BAIT Web

Web institucional estatica para presentar BAIT y sus proyectos de muestra.

## Uso local

Abri `index.html` directamente o servi la carpeta con:

```bash
python -m http.server 8080
```

## Deploy

Subi todo el contenido de esta carpeta a tu hosting estatico o a Nginx.

Si se publica junto al Prode en el mismo VPS, una opcion simple es:

- `https://tudominio.com/` para esta web.
- `https://prode.tudominio.com/` para el Prode Mundial.
